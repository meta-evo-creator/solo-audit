本文是DI技能的核心方法论文件，整合了中纪委官方违纪构成理论、四件套方法论与**五组系统思维增强工具**。**使用时按"三阶段十一步+增强节点"流程执行**。

## 第一部分：中纪委"违规+有责"两因素分析法（基础层）

### 1.1 法规来源

- 《中国共产党纪律处分条例》第七条
- 中纪委案件审理室《"纪理"的概念引入及内涵研究》（中国纪检监察杂志）
- 《中国共产党纪律处分条例》百问百答

### 1.2 核心公式

> **违纪 = 违规性要素满足 + 有责性要素满足 + 无阻却事由**

```
        第一步：违规性判断（客观层面）
            ↓ 满足？
        第二步：有责性判断（主观+责任层面）
            ↓ 满足？
      ╔══════════════╗
      ║  构成违纪    ║
      ╚══════════════╝
```

### 1.3 违规要素（客观层面）——六项

| 要素 | 定义 | 审查问题 | 证据要求 |
|------|------|---------|---------|
| **① 行为主体** | 行为的实施者（党员/公职人员/领导干部/特定身份者） | 主体适格吗？是否有特定身份要求？ | 身份证明材料（党员登记表、任免文件、岗位职责书） |
| **② 危害行为** | 违反党章/法规/政策/道德的具体行为 | 做了什么违规的事？引用的条规是否正确？ | 行为记录（书证、物证、电子数据、证人证言） |
| **③ 危害对象** | 行为侵犯的客体（党的纪律、国家利益、群众利益等） | 侵犯了哪种受保护的法益？ | 客体证明（相关法规条文） |
| **④ 危害结果** | 造成的损害或不良影响 | 造成了什么后果？后果严重程度？ | 结果证据（审计报告、鉴定意见、社会影响评估） |
| **⑤ 因果关系** | 行为与结果之间的客观关联 | 是不是该行为导致的？有无其他介入因素？ | 因果链条证明（时间顺序、逻辑关联、排他性证据） |
| **⑥ 违规阻却事由** | 排除违规性的正当理由 | 有无合法合规的正当理由？（紧急避险、正当履职、上级指令等） | 阻却事由证据（批准文件、紧急情况证明） |

### 1.4 有责要素（主观+责任层面）——五项

| 要素 | 定义 | 审查问题 | 判断标准 |
|------|------|---------|---------|
| **① 故意** | 明知行为违规且希望或放任结果发生 | 当事人是否知道或应当知道？ | 直接故意（明知+追求）；间接故意（明知+放任） |
| **② 过失** | 应当预见违规结果而未预见，或轻信可避免 | 是否尽到了合理的注意义务？ | 疏忽大意（应预见未预见）；过于自信（已预见但轻信可避免） |
| **③ 责任能力** | 是否具备理解和遵守纪律的智力/认知条件 | 当事人是否有能力遵守规则？ | 精神状况、认知水平、信息获取条件、制度培训情况 |
| **④ 目的与动机** | 行为的内在驱动力 | 为什么这么做？是利己还是系统所迫？ | 主观陈述 + 客观环境证据 |
| **⑤ 责任阻却事由** | 不承担责任的正当理由 | 有无不可抗力、被迫、制度强制等免责情形？ | 不可抗力证明、胁迫证据、制度强制依据 |

### 1.5 关键判例参考

| 案例 | 违规性 | 有责性 | 结论 | 推理过程 |
|------|--------|--------|------|---------|
| **漏报个人事项（非故意）** | ✅ 违反报告规定 | ❌ 不满足故意要件 | **不构成违纪** | 漏报≠瞒报，无主观故意 |
| **漏报（情节较重，如房产少报50m²+）** | ✅ 违反规定 | ✅ **推定故意** | **构成违纪** | 情节重大→推定知道且有意 |
| **接受公款宴请** | ✅ 公款支付 | ❌ 不明知是公款 | **不构成违纪** | 主观认知不足时，仅有客观违规不够 |
| **转移涉案财物** | ❌ 所转移非赃物 | ✅ 串通转移意图 | **不构成违纪** | 仅满足有责要素，不满足违规要素 |

## 第二部分：增强模块体系（方法层）

### 2.1 增强模块定位总览

### 2.2 各模块操作细则

#### M1 - 激励相容增强模块

**功能**：在判断违规性时，追问制度本身是否为违规的"推手"

**操作**：

```
发现违规行为后，问：
"同样的制度下，换一个正常人会不会犯同样的错？"
  ├─ 不会 → 制度设计基本合理，进入常规审查
  └─ 会   → 制度存在激励不相容，启动四维检视

威利信德四维检视：
  ☐ 威：违规后果是否明确可预期？
      模糊→当事人可能误判风险
  ☐ 利：合规是否有真实收益？
      违规更有"利"→制度在奖励违规
  ☐ 信：规则是否稳定执行？
      选择执法→当事人认为"运气"决定
  ☐ 德：制度是否在塑造正向身份？
      好人被淘汰→柠檬市场启动

▶ 制度缺陷严重 → 建议先改制度，再视情节处理个人
▶ 制度缺陷较轻 → 标注制度建议，正常走审查流程
```

**理论来源**：Leonid Hurwicz, Mechanism Design Theory

#### M2 - 柠檬市场增强模块

**功能**：在审查证据时，验证判断依据的信号可靠性

**操作**：

```
审查证据信号强度：
  ☐ 强信号（伪造/模仿成本极高）：
    银行流水原件、审计报告、第三方鉴定、时间戳数据
    → 可直接采信，减少交叉验证成本

  ☐ 中信号（可伪造但成本较高）：
    公章文件、视频监控、电子审批记录
    → 需一定交叉验证

  ☐ 弱信号（伪造/模仿成本低）：
    当事人陈述、证人证言（单一口供）、举报信
    → 必须有2个以上独立来源的证据相互印证
    → 每个相关事实至少2个独立证据

  ☐ 伪信号（专为应付审查而制造）：
    事后补的会议纪要、补签的审批单、"迎检台账"
    → 比对"汇报数据"与"运行数据"的偏差
    → 寻找"老周的笔记本"而非只看"刘主任的PPT"

▶ 审查者须意识到自身可能存在信息不对称：
  能看到的都是"台账/文件"（刘主任的数据），
  还是也能看到"实际运行"（老周的数据）？
```

**理论来源**：George Akerlof, "The Market for Lemons" (1970)

#### M3 - 非预期后果增强模块

**功能**：在确定处置方案后，审计其可能带来的副作用

**操作**：

```
确定处置方案后，预判四种非预期后果：

  ☐ 模式1：绕道走
    处置太严厉→违规转向更隐蔽的形式
    → 建议：同步加强监测敏感指标

  ☐ 模式2：挤掉效应
    过度依赖处分→道德自律被"价格"替代
    → 建议：保留正向激励空间

  ☐ 模式3：替代恶化
    堵住A路径→转到更差的B路径
    → 建议：排查可能的替代路径

  ☐ 模式4：时间前移
    运动式处治→短期数据好转，长期问题回潮
    → 建议：设计常态化机制，避免大起大落

▶ 存在显著非预期后果风险 → 调整处置方案
▶ 风险可控 → 建议同步建立监测机制
```

**理论来源**：Robert K. Merton, "The Unanticipated Consequences of Purposive Social Action" (1936)

#### M4 - 追责四层增强模块（核心接口）

**功能**：深化有责性判断，精准定位归责层级

**操作**：

```
有责性判断 → 追问追责归属层级：

┌──────────────────────────────────────────────────────┐
│  第一层：个体过错（Personal Trouble）                   │
│  ─────────────────────────────────────                 │
│  条件：行为人有完全责任能力+具有故意+非制度所迫       │
│  追责方式：纪律处分/司法移送                           │
│  关键问题：同样的制度下，多数人没做→锁定第一层        │
├──────────────────────────────────────────────────────┤
│  第二层：管理失职（Management Failure）                 │
│  ─────────────────────────────────────                 │
│  条件：管理者未尽制度+检查/监督义务                    │
│  追责方式：诫勉谈话/组织处理/领导责任                  │
│  关键问题：制度有规定但执行不到位→锁定第二层          │
├──────────────────────────────────────────────────────┤
│  第三层：制度缺陷（Systemic Flaw）                       │
│  ─────────────────────────────────────                 │
│  条件：制度设计存在漏洞或激励扭曲，正常人也会犯错       │
│  追责方式：整改通知/制度修订/专项治理                   │
│  关键问题：换一个人也会犯同样的错→锁定第三层          │
├──────────────────────────────────────────────────────┤
│  第四层：结构困境（Structural Dilemma）                  │
│  ─────────────────────────────────────                 │
│  条件：各方理性行事但仍产出不良结果                    │
│  追责方式：政策建议/系统性改革推动                      │
│  关键问题：所有人都"对"但结果"错"→不追责推改革       │
└──────────────────────────────────────────────────────┘

追责四层 → 对应有责性判断：
  第一层 = 故意 → 有责性最高
  第二层 = 过失 → 有责性中等
  第三层 = 制度→有责性转移（部分阻却）
  第四层 = 结构→有责性阻却（不追究个人）

▶ 归责层级影响处置方式选择
▶ 超越第一层的追责需同步给出制度改进建议
```

#### M6 - 防线审计增强模块（v2.0新增）

**来源**：詹姆斯·瑞森瑞士奶酪模型——重大事故=多层防线同时穿孔

**功能**：在S1违规行为认定时，不只看"显性失误"，同时追溯"潜在条件"

**操作**：
```
在S1违规行为认定时，补充防线审查五层：

第⑤层·文化层：组织是否默许/纵容此类行为？
第④层·监管层：谁来检查？检查了什么？检查有效吗？
第③层·制度层：制度本身有无漏洞或激励扭曲？（对接M1）
第②层·管理层：管理者有无尽到制度赋予的监督义务？（对接M4第二层）
第①层·操作层：当事人具体做了什么？（显性失误）

输出：
  "显性失误：当事人[姓名]在[某节点]做错了[具体行为]
   潜在条件：第[②-⑤]层防线同时穿孔——[具体描述]"
```

#### M7 - 归因偏差校准模块（v2.0新增）

**来源**：李·罗斯基本归因谬误——人本能高估品质因素，低估处境因素

**功能**：在S4有责性判断时，审查者自检归因偏差

**操作**：
```
在S4有责性判断时，插入三道自检：

☐ 自检1：我是否把当事人行为"本质化"了？
    "他就是个XX的人"→归因偏差警告。改为：在什么环境/激励下他会这样？

☐ 自检2：换一个正常人在同样位置上会不会犯同样的错？
    "会"→有责性至少部分转移至M4第三层（制度缺陷）
    "不会"→锁定M4第一层（个体过错），继续

☐ 自检3：我是否充分考察了处境证据？
    必须调取：制度文件、岗位职责、工作流程、培训记录
    不能只靠：当事人陈述、证人证言
```

**适用场景**：尤其当事人已被贴上标签（如"偏执""不配合""态度差"）。归因校准不改变违规性判断，但影响有责性评价。

#### M8 - 公正文化精细化模块（v2.0新增）

**来源**：戴维·马克思公正文化算法——区分无心之失/冒险行为/鲁莽违规

**功能**：将M4追责四层的第一层"个体过错"进一步拆分为三个子层

**操作**：
```
将M4第一层拆分为三个子层：

第一层A·鲁莽违规：明知重大风险、为私利故意为之
  → 纪律处分/司法移送
  → 案例：收受贿赂、故意造假

第一层B·冒险行为：走捷径、图方便的习惯性偏离
  → 纠正行为+消除制度激励+训练
  → 案例：双人复核改单人、审批跳过签字
  → 原则：人走捷径往往因为系统在奖励走捷径

第一层C·无心之失：疲劳/疏忽/误操作
  → 安慰+修系统+补培训，不追个人
  → 案例：疲劳下看错药名、报警中漏掉步骤
```

**为什么重要**：原第一层笼统"个体过错→纪律处分"易导致两类错误：过度严苛（把无心之失也处分）或过度宽纵（把鲁莽违规归因于制度）。

#### M9 - 替罪羊风险审计模块（v2.0新增）

**来源**：勒内·吉拉尔替罪羊机制——替罪羊不是被找出的原因，而是被选出的出口

**功能**：在S9非预期后果审计中增加替罪羊风险自检

**操作**：
```
在S9非预期后果审计中，增加三项替罪羊审计：

☐ 审计1：方案满足的是"有人被处理了"的情绪需求，还是"系统漏洞被修复了"的实际需要？
    → 只有人处理没有制度改进→"存疑方案"

☐ 审计2：只处理人、不修制度，同类问题三个月后会不会复发？
    → 会复发→必须补充制度改进

☐ 审计3：被追责的人是真应负主要责任，还是因"离事故最近"所以最易被推出？
    → 是后者→回溯M6防线审计

▶ 三项全通过→方案合理。任一未通过→调整方案，补充制度改进。

附加：重大事故后、问责压力大时，替罪羊风险最高——审查者须有意识抵御"速推替罪羊"的压力。
```

```
│  │后果审计  │  │+处置方案 │  │建议输出  │              │
│  └────┬─────┘  └──────────┘  └──────────┘              │
│       │                                                │
│  M9(替罪羊审计)                                        │
└───────────────────────────────────────────────────────────┘
```

### 3.2 分步操作细则

#### 第一阶段：事实认定（基础）

**S1 - 违规行为认定**
- 确定涉嫌违反的具体条规
- 描述具体行为事实（时间、地点、方式、频率、持续时间）
- 引用具体条规对照（条-款-项精确对应）
- 所需工具：CA法规库（针对法规原文搜索）
- 增强模块：[激励相容] 同步标记制度是否可能"逼"出该行为

**S1a - 防线审计（v2.0新增，调用M6）**
- 在S1违规行为认定的同时，补充防线审查五层
- 输出：显性失误+潜在条件并列呈现
- 详见M6

**S2 - 主体身份确认**
- 确认身份：党员/公职人员/领导干部/特定岗位
- 检查岗位职责对应的制度义务
- 确认责任能力：年龄、精神状况、专业背景

**S3 - 因果关系与结果判断**
- 确认行为与结果之间的时间逻辑关联
- 排除其他介入因素
- 量化结果严重程度
- 证据标准：违纪案件2个以上独立来源证据相互印证

**S4 - 有责性判断（核心）**
- 故意/过失认定
  - 明知规章+主动违反→故意
  - 应知规章+疏忽大意→过失
  - 不知规章+培训到位→可能阻却
- 目的动机分析
- 情节轻重甄别

**S4a - 归因偏差校准（v2.0新增，调用M7）**
- 在进行有责性判断的同时，审查者做三道自检
- 详见M7

**S5 - 阻却事由审查**
- 违规阻却：紧急避险、正当履职、上级合法指令
- 责任阻却：不可抗力、胁迫、非自愿、制度强制

#### 第二阶段：增强分析（方法）

**S6 - 激励相容增强（制度溯源）**
- 追问制度激励是否有问题
- 使用威利信德四维框架
- 输出：制度缺陷评估（无/轻/重）

**S7 - 柠檬市场增强（信号审计）**
- 证据信号强度评级（强/中/弱/伪）
- 弱信号须2个以上独立来源
- 输出：证据可靠性评估表

**S8 - 追责四层增强+公正文化精细化（归责定位，调用M4+M8）**
- 有责性判断与追责四层对接
- 如归责在第一层，启动M8公正文化精细化：
  - 第一层A（鲁莽）→纪律处分
  - 第一层B（冒险）→纠正+改制度
  - 第一层C（无心）→修系统，不追人
- 输出：归责层级+公正文化分类+量纪建议

#### 第三阶段：结论输出（结果）

**S9 - 非预期后果审计+替罪羊风险审计（调用M3+M9）**
- 预判四种非预期后果
- 追加M9替罪羊审计：三项自检
- 输出：风险提示+替罪羊风险结论

**S10 - 综合定论与处置方案**
- 违纪事实结论
- 归责层级结论
- 处置建议

**S11 - 制度改进建议输出**
- 第三层→制度修订方向
- 第四层→系统性改革建议
- 第二层→管理机制优化
- 第一层→防控建议

| "这事怎么定性？"（事后） | DI两因素+增强分析 | 全流程 |

### 4.2 模块调用优先级

```
高频 → M4追责四层+M8公正文化（每次归责时用）+ M7归因校准（每次定性时用）
中频 → M1激励相容（制度性问题）+ M2柠檬市场（证据存疑时）
低频 → M6防线审计（系统性案件）+ M3非预期后果+M9替罪羊（处置方案定型后）
```

### 4.3 与CA的分工边界

| 维度 | CA（合规分析） | DI（纪检审查） |
|------|--------------|--------------|
| 时间点 | 事前 | 事后 |
| 核心问题 | "能不能做？" | "做了怎么定性？" |
| 依据 | 法规原文+合规义务 | 法规原文+违规+有责+归责 |
| 增强模块 | 可引用激励相容/柠檬市场思维 | 全流程九模块整合 |
| 输出 | 合规判断+风险等级 | 违纪定性+归责层级+处置方案+制度建议 |

### 4.4 伦理边界

1. **DI不能替代司法审判**：重大案件移送司法机关后，以司法机关结论为准
2. **两因素交叉验证**：增强模块中的制度缺陷评估不能作为免责的唯一理由
3. **证据排除规则**：弱/伪信号证据不得单独作为定性依据
4. **容错与申诉**：任何处置方案须保留当事人的申辩权和申诉渠道
5. **透明可追溯**：所有判断过程应记录留痕，供后续审计
