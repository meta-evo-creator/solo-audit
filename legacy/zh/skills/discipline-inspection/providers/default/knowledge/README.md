## 如何获取完整法规库

### 选项1：配置 WIKI 法规库（推荐）

如果你有中山一院纪检 WIKI 法规库：
```bash
export WIKI_PATH=/path/to/wiki/main/sources
```
管线自动切换为 wiki-provider（45+部法规 + 11个指导性案例）。

### 选项2：自行构建法规库

1. 从以下官方来源下载法规全文：
   - [国家法律法规数据库](https://flk.npc.gov.cn/)
   - [中央纪委国家监委网站](https://www.ccdi.gov.cn/fgk/)
   - [中国政府网](https://www.gov.cn/)
2. 将法规保存为 Markdown 文件，放入 `法规/` 目录
3. 管线通过 ripgrep 自动检索

### 选项3：配置北大法宝

如果你有北大法宝（PKULaw）订阅：
1. 配置 `pkulaw-mcp` 服务
2. 安装 `pkulaw-search` 技能
3. 管线自动叠加版本验证能力
