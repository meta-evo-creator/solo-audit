# Legacy Chinese originals

This directory holds the Chinese-language originals: the pre-6.13 audit specification, the earlier
reference set, and the bundled subject-matter packages that were carried in this repository before the
English edition.

Two reasons the material is kept rather than deleted:

1. **Statutory texts are not translated.** The regulation texts in
   `skills/discipline-inspection/providers/default/knowledge/` are Chinese law. A translation of a
   statute is a commentary, not the statute; citing a translation as the provision would be wrong.
   They stay in the original language.
2. **History is evidence.** The audit layer's own rule is that a record is appended, never rewritten.
   Superseded versions are archived here, not overwritten in place.

Where a Chinese file and its English counterpart disagree, the English file in the main tree governs
for this repository's purposes, and the Chinese original governs as the record of what was actually
operational at the time.

Untranslated packages here (deep-research, msf, mev-engine, discipline-inspection, file-transfer,
superocr) are separate capabilities that were bundled with the audit tooling. They are not part of the
audit specification and are not maintained in English.
