# 膨胀陷阱护栏 — 强制执行标准

> 五原则基石。不是提醒——是门禁。

## 触发条件

修改以下文件前强制触发：SOUL.md / AGENTS.md / MEMORY.md / skill SKILL.md / agent .md

## 执行步骤

修改前必须先输出：

```
我即将在 [文件] 中：
  新增: [N]行 — [具体内容描述]
  删除: [M]行 — [被替代的旧内容描述]
  净变化: [N-M]行
  原因: [为什么不能通过消路径解决？]
```

## 门禁规则

| 净变化 | 结果 |
|:--:|:-----|
| ≤0 | ✅ 压缩/重构 |
| >0 有对应删除 | ✅ 替换 |
| >0 无对应删除 | 🔴 膨胀—需审批 |
